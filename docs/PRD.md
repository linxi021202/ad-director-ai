# PRD：AdDirector AI / AI 广告导演台

## 项目背景

AdDirector AI 面向需要快速制作电商、品牌和社交媒体广告的创作者与品牌团队。产品把商品信息拆成策略、分镜、视觉提示词、关键帧、主镜头视频和最终成片，并让每一步的模型、状态和降级路径可见。

## 核心用户

- 电商和品牌运营人员。
- 社交媒体内容创作者。
- 需要快速验证广告创意的小型团队。
- 需要演示多模型工作流的产品与技术人员。

## 当前主链路

```text
商品简报 -> DeepSeek -> Qwen-Image -> HappyHorse -> Remotion
```

- DeepSeek：策略、动态分镜、图片提示词、视频提示词。
- Qwen-Image：逐镜头关键帧。
- HappyHorse：一个主镜头视频。
- Remotion：旁白、字幕、卖点、CTA 和完整 MP4。

## 新项目规格

- 新项目默认 8 个镜头 × 5 秒，共 40 秒。
- 默认 8 个镜头。
- 默认镜头时长：4、5、5、5、6、5、5、5 秒。
- 默认第 5 镜为主镜头。
- 支持 9:16、16:9、1:1。
- 支持 3–12 个镜头，每个镜头独立设置 3–8 秒；总时长动态求和。

旧项目保留自身镜头数和时长，不自动迁移。

## 用户旅程

1. 用户填写或恢复商品简报。
2. DeepSeek 生成策略、分镜和全部提示词。
3. Qwen-Image 按每个镜头的独立提示词生成关键帧。
4. 用户选择主镜头。
5. HappyHorse 使用真实产品参考图、主镜头关键帧和视频提示词生成视频；失败时允许手动导入。
6. Remotion 生成旁白并合成关键帧、主镜头、字幕、卖点和 CTA。
7. 用户预览并下载私有 MP4。
8. 刷新或返回生成页时，项目和生成日志继续恢复。

## 状态与失败处理

正式状态由服务端 GenerationEvent 驱动。关键帧支持部分成功；DeepSeek 失败可回退 Mock；HappyHorse 失败可手动导入或使用关键帧动效；Remotion 失败保留可重试状态。

## 安全边界

- API Key 仅在服务端按匿名 Session 解析。
- 项目和媒体均校验匿名会话所有权。
- Qwen 临时 URL 不作为永久资产。
- 日志不保存密钥、Authorization、Session ID、渲染令牌、绝对路径或完整上游响应。

## 非目标

当前不做登录、支付、多人协作、多视频供应商路由、云端对象存储和分布式渲染队列。
