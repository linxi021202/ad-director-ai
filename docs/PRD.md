# PRD: AdDirector AI / AI广告导演台

## 项目背景

AIGC广告视频正在从“单点生成工具”转向“可控工作流产品”。真实广告生产不是输入一句话直接出视频，而是先明确商品、受众、卖点、平台语境，再拆解策略、分镜、Prompt、模型路由、成本与降级方案。

AdDirector AI 是一个 10 天内单人可落地的 AI 产品经理面试 Demo。它不追求真实商业闭环，而是用一个可解释、可演示、工程结构清晰的 MVP，证明候选人理解多模型 AIGC 产品如何从需求、流程、成本和失败处理上被设计出来。

第一阶段只使用 Mock Provider，不接真实 AI API。项目重点不是 API 套壳，而是把“多模型广告生成工作流”产品化。

## 用户画像

目标用户是面试场景中的 AI 产品经理候选人。

候选人需要在有限时间内向面试官展示：
- 能把 AIGC 能力拆成产品流程，而不是停留在模型调用。
- 能设计可解释的生成链路，让输出结果有业务理由。
- 能考虑模型成本、质量、延迟和失败降级。
- 能把产品文档、架构、Demo 和代码组织成一个可落地项目。

间接受众是面试官，尤其关注候选人的产品判断、工程边界、MVP意识和对 AIGC 工作流的理解。

## 核心需求

1. 用户能看到一个明确的 AI 广告导演台产品定位。
2. 用户能在生成页看到固定商品 Brief：低糖冷萃咖啡，一线城市上班族。
3. 用户点击生成后，系统展示完整广告生成链路。
4. 系统输出广告策略、4 个镜头分镜、图片 Prompt、视频 Prompt。
5. 系统展示每个阶段使用哪个模型、为什么使用、预计成本与延迟。
6. 系统展示低成本模式和质量优先模式的成本区间。
7. 系统展示失败降级方案：视频失败时降级为关键帧 + Remotion 图片动效视频。
8. 项目详情页能作为面试演示的完整结果页。

## MVP范围

MVP 只做一个主 Demo 场景：低糖冷萃咖啡，目标用户为一线城市上班族，平台为抖音/小红书竖版广告。

输出规格：
- 9:16 竖版广告
- 18 秒
- 4 个镜头
- 每个镜头包含目标、画面描述、景别、摄影机运动、字幕、Prompt、推荐模型、降级方案

工程范围：
- Next.js App Router
- TypeScript
- Tailwind CSS
- Zod Schema
- Mock Provider
- 本地 mock 数据
- 基础测试：Schema 和 Provider Router

## 用户旅程

1. 用户进入首页，理解这是 AI 广告导演台，而不是普通视频生成器。
2. 用户点击“开始生成Demo”。
3. 生成页左侧展示商品输入表单，右侧展示生成流程状态。
4. 用户点击生成按钮。
5. 页面展示 coldBrewDemo mock 结果：策略、分镜、Prompt、模型路由、成本、视频预览。
6. 用户进入项目详情页，完整讲解从 Brief 到最终预览的生成逻辑。
7. 面试官追问成本、模型选择或失败情况时，候选人能直接指向页面模块说明。

## 页面流程

首页 `/`：
- 产品名：AdDirector AI / AI广告导演台
- 一句话定位
- 核心亮点：AI导演模式、Prompt可解释、成本感知模型路由、失败降级
- 入口按钮：开始生成Demo、查看样例项目

生成页 `/generate`：
- 左侧商品输入表单
- 生成按钮
- 成本模式说明
- 右侧生成时间线
- 点击生成后展示 mock 结果

项目详情页 `/projects/[id]`：
- 商品 Brief
- 广告策略卡片
- 4 个分镜卡片
- Prompt 解释面板
- 模型路由表
- 成本预估卡片
- 生成时间线
- 最终视频预览占位

## 功能模块

- Product Brief：定义商品、平台、目标用户、比例、时长和风格。
- Strategy：生成用户洞察、痛点、核心信息、情绪钩子和 Big Idea。
- Storyboard：将广告拆成 4 个可执行镜头。
- Prompt Explain：展示图片和视频 Prompt，解释生成意图。
- Model Routing：展示任务到模型的选择逻辑。
- Cost Estimate：对比低成本模式和质量优先模式。
- Generation Timeline：展示 strategy/copy/image/video/render 五个阶段。
- Video Preview：当前为 mock 占位，后续可替换真实 mp4。
- Fallback：视频生成失败时降级为图片动效视频。

## 非目标功能

第一阶段不做：
- 登录、注册、多用户
- 支付、订单、套餐
- 数据库和云存储
- 真实 AI API 调用
- 真实视频渲染队列
- 多商品、多行业模板
- 权限系统
- 复杂素材管理
- 在线协作
- 商业级导出和版权审核

这些能力可以放到后续版本，但不进入 10 天 MVP。
